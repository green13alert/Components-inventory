# Jumper wires

Canonical visual reference for the Dupont jumper wires (`jumper-wires` in the Solderi catalogue). The catalogue lists male-to-male among its aliases.

Future reference images in this folder should represent those wires' canonical physical appearance.

Reuse this reference in any Solderi visual where the same physical jumper wires appear.

If this canonical reference exists, do not introduce a generic substitute.
